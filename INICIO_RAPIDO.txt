FRIDAY — INÍCIO RÁPIDO

ANDROID (TERMUX): instalação nova: `bash termux/instalar-termux.sh`. Atualização: leia INSTALAR_ATUALIZACAO.md.
LINUX: rode `bash EXECUTAR_FRIDAY.sh`.
WINDOWS: rode `EXECUTAR_FRIDAY.bat` (requer Python 3 instalado).

O inicializador oferece menu para iniciar a assistente, iniciar a API híbrida,
executar diagnóstico ou instalar dependências. Ele não executa comandos de sistema
ocultos, não cria persistência no boot e não copia código para outros dispositivos.
Configure segredos apenas no .env local; nunca os publique.
